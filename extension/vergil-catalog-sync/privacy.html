Schedule refresh privacy policy

Effective August 24, 2026

Single purpose

This extension helps keep LionPlan course schedules current by capturing the public course times and locations already returned by Vergil course search.

What it processes

The extension processes course identifiers, term and section codes, call numbers, meeting days, times, building and room labels, and the time each result was observed. Captures are stored only in Chrome's session storage and disappear when the browser session ends or when you choose Clear.

What it never accesses

It does not read passwords, bearer tokens, request headers, cookies, browser history, planner or schedule records, registration actions, grades, holds, financial information, or any other personal academic record. It never sends a request to a Columbia API and never performs a registration action.

Sharing and consent

Sharing is disabled by default. If you explicitly enable Help keep the catalog current, only the signed-in LionPlan website may request the sanitized capture. You review the contribution on that site before it is submitted. No data is sold, used for advertising, or transferred for an unrelated purpose.

Limited Use

Use of information received through this extension adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide and improve the extension's disclosed schedule-refresh purpose.
